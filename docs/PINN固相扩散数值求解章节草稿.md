# PINN 求解 P2D 模型固相扩散方程

## 控制方程与无量纲化

P2D 模型中，正负极活性材料颗粒通常近似为球形颗粒。若假设固相扩散系数为常数，则颗粒内部固相锂浓度满足球坐标扩散方程：

```text
∂c_s/∂t = D_s / r^2 * ∂/∂r(r^2 ∂c_s/∂r),     0 < r < R_s
```

其中 `c_s` 为固相锂浓度，`D_s` 为固相扩散系数，`R_s` 为颗粒半径。展开后可写为：

```text
∂c_s/∂t = D_s(∂²c_s/∂r² + 2/r * ∂c_s/∂r)
```

为提高神经网络训练稳定性，引入无量纲变量：

```text
x = r / R_s
tau = D_s t / R_s²
c = (c_s - c_s0) / c_scale
```

得到无量纲固相扩散方程：

```text
∂c/∂tau = ∂²c/∂x² + 2/x * ∂c/∂x,     0 < x < 1
```

## 初始条件与边界条件

本文采用初始均匀浓度条件：

```text
c(x, 0) = 0
```

球心处由对称性给出 Neumann 边界：

```text
∂c/∂x(0, tau) = 0
```

颗粒表面由固液界面反应通量控制：

```text
-D_s ∂c_s/∂r |_(r=R_s) = J_surf
```

无量纲化后得到：

```text
∂c/∂x(1, tau) = -phi
phi = J_surf R_s / (D_s c_scale)
```

本算例取恒定无量纲通量 `phi = 0.2`，计算时间区间为 `tau ∈ [0, 0.4]`。需要指出，恒定通量从 `tau=0+` 瞬时施加时，初始均匀浓度与表面通量边界在 `(x=1,tau=0)` 角点不相容。因此，残差和边界误差评价应区分全域误差与排除初始角点后的误差。

## PINN 构造

为避免初始条件和球心边界仅通过罚函数近似满足，本文采用硬约束网络形式：

```text
c_PINN(x, tau) = tau * N(2x² - 1, 2tau/tau_max - 1)
```

其中 `N` 为全连接神经网络。该构造具有两个性质：

```text
c_PINN(x, 0) = 0
∂c_PINN/∂x(0, tau) = 0
```

因此，初始条件和球心对称边界在网络结构上严格满足。训练损失仅对控制方程残差和表面通量边界进行优化：

```text
L = L_pde + 40 L_flux
```

其中：

```text
L_pde = mean[(∂c/∂tau - ∂²c/∂x² - 2/x * ∂c/∂x)²]
L_flux = mean[(∂c/∂x(1,tau) + phi)²]
```

网络采用 `4` 个隐藏层，每层 `64` 个神经元，激活函数为 `tanh`。训练过程先使用 Adam 优化，再使用 L-BFGS 精修。为提高初始阶段和表面通量边界附近的精度，配点中包含早期时间加密采样和表面边界时间网格采样。

## 参考解与验证指标

为验证 PINN 解的可信性，本文采用有限体积法作为参考解。有限体积离散直接基于球形控制体积分形式，能够保持扩散通量守恒。PINN 解在相同无量纲网格上与有限体积参考解比较。

当前计算得到的主要误差指标如下：

```text
RMSE against finite-volume reference: 7.92434450e-04
Max error against finite-volume reference: 1.92953038e-03
Mass balance RMS error: 7.30423224e-04
Mass balance max abs error: 1.20238572e-03
Initial condition RMS error: 0.00000000e+00
Initial condition max abs error: 0.00000000e+00
Center symmetry max abs slope: 0.00000000e+00
```

对于表面通量边界，若包含 `tau≈0` 的不相容角点，全域最大误差会被角点放大。排除 `tau < 1e-4` 后，表面通量边界误差为：

```text
Surface flux RMS error, tau >= 1e-4: 6.98540593e-04
Surface flux max abs error, tau >= 1e-4: 3.47931077e-03
```

排除初始角点后的 PDE 残差指标为：

```text
Autograd PDE residual RMS, tau >= 1e-4: 2.65104716e-02
Autograd PDE residual p99 abs, tau >= 1e-4: 8.09368059e-02
Autograd PDE residual max abs, tau >= 1e-4: 8.27352684e-01
```

其中最大残差仍主要出现在靠近早期时间和表面边界的局部区域；从误差场和有限体积参考解对比看，该局部残差并未导致浓度解出现明显偏移。

## 结果分析

径向浓度分布显示，随着 `tau` 增大，颗粒表面浓度变化快于颗粒中心，浓度沿半径方向形成由表面向中心传播的梯度。这与恒定表面通量驱动下球形颗粒扩散的物理图像一致。

PINN 与有限体积参考解在 `tau = 0, 0.1, 0.2, 0.3, 0.4` 处的径向浓度曲线基本重合。点误差场显示，整个计算域内误差量级保持在 `10^-3` 左右，最大误差小于 `2e-3`。质量守恒验证中，PINN 体平均浓度与由表面通量积分得到的理论体平均浓度高度一致，说明 PINN 解不仅局部满足扩散方程，而且整体通量守恒关系也得到较好保持。

综上，该硬约束 PINN 能够稳定求解常扩散系数下的 P2D 固相球形扩散方程。相较于仅用软损失约束初始条件和边界条件的 PINN，硬约束形式显著改善了初始条件满足程度和与参考解的一致性。该结果可作为 PINN 求解 P2D 固相扩散子问题的数值验证结果写入论文，但论文中应明确说明恒定通量启动时的初始角点不相容性，并报告排除该角点后的边界残差和 PDE 残差。
